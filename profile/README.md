NiuTrans Open Source (https://github.com/NiuTrans/) develops open-source tools and technologies for large language model (LLM)-powered translation and natural language processing. The project is jointly maintained by the NLP Lab at Northeastern University and NiuTrans Research. In addition to these open-source projects, our official translation services are available at https://niutrans.com/ and https://vip.niutrans.com/.
