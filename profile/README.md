NiuTrans Open Source develops large language model (LLM)-powered translation
and natural language processing technologies. The organization is maintained
by the NLP Lab at Northeastern University and NiuTrans Research.

Our official services are available through the following platforms:

- [NiuTrans Cloud/小牛翻译云平台](https://niutrans.com/) — Online large language model (LLM)-powered translation services and APIs for individuals, developers, and enterprises.
- [NiuTrans Enterprise Cloud/小牛翻译企业云平台](https://vip.niutrans.com/) — Large language model (LLM)-powered document translation services for enterprises.
