# NiuTrans Open Source

NiuTrans Open Source develops large language model (LLM)-powered translation
and natural language processing technologies. The organization is maintained
by the NLP Lab at Northeastern University and NiuTrans Research.

## Official NiuTrans Services

- [NiuTrans Cloud](https://niutrans.com/) — Online large language model (LLM)-powered translation services and APIs for individuals, developers, and enterprises.
- [NiuTrans Enterprise Cloud](https://vip.niutrans.com/) — Large language model (LLM)-powered document translation services for enterprises.

## Explore Our Work

Browse our [public repositories](https://github.com/orgs/NiuTrans/repositories)
for projects related to machine translation, natural language processing,
multilingual models, developer tools, books, and research.

# NiuTrans开源

小牛翻译开源致力于大模型翻译与自然语言处理技术的研发，由东北大学自然语言处理实验室和小牛翻译研究团队共同维护。

## 小牛翻译官方服务

- [小牛翻译云平台](https://niutrans.com/) — 面向个人用户、开发者与企业的在线大模型翻译服务及 API。
- [小牛翻译企业云平台](https://vip.niutrans.com/) — 面向企业的大模型文档翻译服务。
